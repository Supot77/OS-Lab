1. Execution Time Comparison:
- Sequential Time: 8.93 seconds
- Multithreading Time: 8.73 seconds
- Multiprocessing Time: 7.71 seconds

2. System Observation (htop):
During the multithreading run, the work did not use both CPU cores very well
because of Python's GIL. During the multiprocessing run, separate processes
could run at the same time, so htop showed better use of the two logical
CPUs. Multiprocessing was faster, even though creating processes also took
some time.

3. Analysis (The GIL):
Multithreading did not make the CPU work much faster because the GIL allows
only one thread to run Python code at a time in one process. The threading
time was 8.73 seconds, which was close to the sequential time of 8.93
seconds. Multiprocessing is better for CPU-heavy tasks, such as ML data
augmentation, because each process has its own Python interpreter and GIL.
This allows the processes to use more than one CPU core. In this test,
multiprocessing was fastest at 7.71 seconds.
